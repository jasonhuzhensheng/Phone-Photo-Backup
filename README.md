# Phone Photo Backup

An early-stage project scaffold for a local phone photo backup tool.

**Current status:** No backup functionality has been implemented. Supported phone platforms, photo import method, destination, and recovery behavior remain to be decided. See [handoff.md](handoff.md) for the current status and next steps.

Personal photos, videos, exported backups, credentials, and local databases must never be committed to this repository. Use simulated or temporary media for development and tests.
